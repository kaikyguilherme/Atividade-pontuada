# Portfólio — Kaiky Guilherme

Site estático em HTML, CSS e JavaScript. Para visualizar localmente, abra `index.html` no navegador. Ao publicar, envie todos os arquivos HTML, `portifolio.css` e `portifolio.js`.

## Páginas

- `index.html` — Sobre mim e página inicial.
- `certificacoes.html` — Formação e certificações.
- `habilidades.html` — Habilidades técnicas.
- `projetos.html` — Projetos e espaço para novidades.
- `contato.html` — E-mail, WhatsApp, GitHub e LinkedIn.

A foto exibida nas páginas inicial e de contato está em `portifolio/assets/minhafoto.jpg`. Em `contato.html`, atualize o endereço genérico do LinkedIn para o link do seu perfil.
